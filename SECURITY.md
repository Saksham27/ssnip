# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting: open the [Security tab](https://github.com/Saksham27/ssnip/security) and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include the SSnip version, your Windows version, and steps to reproduce.

**Never include cookies, tokens, passwords or personal URLs in a report.** If a log contains them, remove them before attaching it.

## Supported versions

Only the latest release receives security fixes.
